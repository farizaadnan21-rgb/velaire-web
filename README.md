# VELAIRE PERFUME — Official Web Experience

> *"In the Heart of the Fragrant VELAIRE — Classic soul, modern scent."*

Landing page modern dan responsif untuk brand parfum mewah **VELAIRE PERFUME**, direkonstruksi dengan standar web modern (HTML5, CSS3, Vanilla JavaScript) serta dilengkapi fitur interaktif katalog, mini cart WhatsApp, scent finder, dan ambient audio player.

---

## ✨ Fitur Utama

1. **Header & Navigation**:
   - Logo Monogram resmi VELAIRE (PNG transparan HD).
   - Sticky navbar dengan efek blur saat di-scroll dan indikator active menu (ScrollSpy).
   - Menu drawer responsif untuk perangkat mobile.

2. **Hero Section (Home)**:
   - Replikasi tipografi Canva dengan latar botanical bertekstur.
   - Slogan *"Welcome to Velaire PERFUME — Classic soul, modern scent"*.
   - Trio Showcase 3 varian (*Velaire MyÓtte*, *Velaire Auréntte*, *Velaire Coondette*).

3. **Intro Section & Ambient Studio**:
   - Slogan *"Your secret scent, bottled"* berpadu foto editorial botol.
   - **Visual / Poster Switcher**: Pilihan antara *Trio Atelier Poster*, *Botanical Garden Poster*, dan *Golden Silk Motion Video*.
   - **Ambient Soundtrack Player**: Pemutar musik santai (*Parisian Atelier*, *Secret Garden*, *Classic Lounge*) lengkap dengan visualizer equalizer animasi.

4. **About Us & Scent Architecture**:
   - Filosofi dan visi merek VELAIRE.
   - Galeri 3 potret botol eksklusif.
   - Diagram anatomi bahan (*Alcohol Denat.*, *Fragrance/Essential Oils*, dan *Aqua Demineralisata*).

5. **Our Varian (Katalog Produk)**:
   - Filter tab kategori (*All*, *Sweet & Floral*, *Aquatic & Fresh*, *Warm & Woody*).
   - Foto resolusi tinggi (2400px) untuk setiap varian 30ml:
     - 🌸 **Velaire MyÓtte**: *Sweet, Fruity, Floral, Fresh & Elegant* (Raspberry, Peony, Praline)
     - 🌊 **Velaire Auréntte**: *Aquatic, Fresh & Floral* (Ocean Breeze, Freesia, Chamomile, Lily of the Valley, Musk)
     - 🪵 **Velaire Coondette**: *Warm, Woody, Amber & Sophisticated* (Bergamot, Cardamom, Lavender, Sandalwood, Amber)
   - **Scent Profile Bars**: Grafik visual tingkat *Freshness*, *Sweetness*, *Warmth*, dan *Longevity*.
   - **Modal Pop-up Detail Aroma**: Rincian piramida aroma lengkap.
   - **Interactive Scent Finder Quiz**: Rekomendasi varian instan berdasarkan preferensi suasana.

6. **Mini Cart & WhatsApp Multi-Item Checkout**:
   - Tas belanja interaktif untuk menambah beberapa varian dan mengatur kuantitas (`+` / `-`).
   - Kalkulasi otomatis subtotal dan total harga (`Rp 20.000,-/botol`).
   - Tombol satu klik kirim rincian pesanan langsung ke WhatsApp admin.

7. **Press & Social Contact**:
   - Banner botol di atas hamparan bunga aster putih berpadu kaligrafi *"In the Press Of Velaire"*.
   - Kontak lokasi (Depok, Jawa Barat), Jam operasional, tautan resmi Instagram (`@velaire.scent`) dan TikTok (`@velaire.scent`).
   - Nomor WhatsApp resmi: `0838-7202-3645`.

## 🚀 Menjalankan Secara Lokal

Cukup buka file `index.html` langsung di browser, atau jalankan server lokal:

```bash
# Menggunakan Python
python3 -m http.server 8080

# Lalu buka di browser:
http://localhost:8080
```

---

## 🛠️ Teknologi

* **HTML5**: Semantik, aksesibel, dan terstruktur.
* **CSS3**: Variabel CSS, flexbox, CSS grid, glassmorphism, animasi keyframes, dan responsive breakpoints.
* **Vanilla JavaScript**: Tanpa ketergantungan framework eksternal, cepat, ringan, dan mudah di-host di mana saja (GitHub Pages, Vercel, Netlify).
